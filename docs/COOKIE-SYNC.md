# 油猴脚本：从浏览器导入 / 更新账号

`dual-runtime/tools/ais2api-cookie-sync.user.js` 是一个 Tampermonkey（油猴）脚本。在浏览器里登录 Google、打开 AI Studio 后，
点一下就能把当前登录状态导入到**你自己部署的** AIS2API 账号池，或者刷新已导入账号的 Cookie。

脚本里不带任何服务器地址和密钥。每个人装好后，在脚本里填自己服务器的地址和同步密钥即可。

## 准备

- 已部署好的 AIS2API，管理后台能从浏览器访问（例如 `https://ais.example.com`）。
- 浏览器装好 **Tampermonkey**。其他脚本管理器（如 Violentmonkey）没有 `GM_cookie`，读不到 HttpOnly Cookie，不能用。
  - 手机上可以用 Kiwi、Edge 等支持扩展的浏览器。

## 第 1 步：在服务器上生成同步密钥

同步密钥由服务器的第一个 API Key 计算出来（HMAC-SHA256），**不是 API Key 本身**，只能用来导入和刷新账号，
不能调用模型，也不能登录管理后台。在服务器上执行：

```bash
node dual-runtime/tools/cookie-sync-key.js
# 或指定配置文件：node dual-runtime/tools/cookie-sync-key.js /path/to/coordinator.json
# 或直接给 API Key：API_KEY=sk-xxx node dual-runtime/tools/cookie-sync-key.js
```

输出是一串 64 位十六进制字符，就是同步密钥。更换第一个 API Key 后同步密钥也会变，脚本里要重新填。

## 第 2 步：安装脚本

1. 打开 Tampermonkey 管理面板 → **新建脚本**，删掉默认内容，粘贴 `ais2api-cookie-sync.user.js` 的全部内容并保存。
   也可以直接在浏览器里打开 GitHub 上这个文件的 Raw 链接，Tampermonkey 会弹出安装页。
2. Tampermonkey **设置** → 配置模式选“高级” → **安全** → “允许脚本访问 Cookie”选 **全部**。
   不改这一项，脚本读不到登录 Cookie，导入会失败。

## 第 3 步：填写服务器地址和同步密钥

1. 打开 <https://aistudio.google.com>，页面右下角会出现一排按钮（点 `AIS` 可以折叠）。
2. 点 **设置**（或在油猴菜单里选“设置服务器地址和同步密钥”）：
   - 第一个框填管理后台地址，例如 `https://ais.example.com`。可以不写 `https://`，末尾的 `/` 会自动去掉。
   - 第二个框填第 1 步生成的同步密钥。以后再改地址时，这一框留空就会保留原来的密钥。
3. 保存后脚本会自动测试一次连接：
   - **连接正常，同步密钥有效 ✓**：可以用了。
   - **同步密钥无效**：密钥填错了，或服务器换过 API Key。
   - **连不上服务器**：检查地址。Tampermonkey 第一次访问这个域名时会弹出跨域确认，选 **总是允许此域名**。

随时可以在油猴菜单里点 **测试连接** 再检查一次。地址和密钥只保存在本机的 Tampermonkey 里，不会写进脚本文件。

## 使用

页面上的按钮：

| 按钮 | 作用 |
|---|---|
| 设置 | 修改服务器地址和同步密钥 |
| 检查 | 只检查 Cookie 是否完整，不导入 |
| 导入 | 当前账号已在池里就更新 Cookie，不在就新建 |
| 分类 | 新账号的分类，每点一次轮换：普通 → Pro → Ultra 5x → Ultra 20x |
| 名称 | 新账号在后台显示的名称，可以留空 |

- **分类和名称只对新导入的账号生效。** 更新已有账号时，后台会保留原来的分类和名称，要改请到管理后台改。
- 分类决定每天的额度和能不能用 4a（`gemini-4-argon`）等高级模型，请按账号实际的订阅选：

  | 分类 | 4a | Pro 模型 | Flash |
  |---|---|---|---|
  | 普通 | 10 | 10 | 100 |
  | Pro | 50 | 50 | 100 |
  | Ultra 5x | 100 | 100 | 500 |
  | Ultra 20x | 200 | 200 | 500 |

  额度每天北京时间 15:00 统一重置。
- 导入后服务器会用这份 Cookie 实际打开一次 AI Studio 验证，页面上会显示结果（约 30 秒到几分钟）。
- 油猴菜单里可以开启 **自动同步**：打开 AI Studio 时和之后每 10 分钟检查一次，Cookie 变了才上传，**只更新已导入的账号**，不会新建账号。

## 常见问题

- **提示“这是浏览器里的第 N 个 Google 账号”**：服务器只会使用第 1 个登录的账号（`authuser=0`）。
  请在浏览器里只登录这一个账号，或用无痕窗口单独登录后再导入。
- **提示缺少 `__Secure-1PSIDTS`**：多半是“允许脚本访问 Cookie”没有选“全部”。点“检查”可以看到详细的读取情况。
- **请求太频繁**：同步接口每分钟最多 20 次，稍等再试。

## 安全

- 同步密钥能往你的账号池里加账号，别公开。泄露后更换服务器第一个 API Key 即可让旧密钥失效。
- 脚本只读取 google.com 的 Cookie 和 AI Studio 页面的 localStorage，只发到你设置的服务器，检查报告里不显示 Cookie 的值。
- 也可以把地址和密钥直接写进脚本顶部的 `DEFAULT_SERVER`、`DEFAULT_KEY` 给自己用，但这样的文件**不要分享**。
